#  Superstore Sales Performance Dashboard

##  Objective
To create an interactive Power BI dashboard that visualizes sales performance by product category, region, and time period.

##  Tools Used
- Power BI Desktop
- Dataset: Superstore Sales (CSV format)

## Dashboard Features
- **Line Chart**: Sales trend over months and year
- **Bar Chart**: Sales distribution by region
- **Donut Chart**: Sales by product category
- **Map Visualization**: State-wise sales performance
- **Stacked Bar**: Sales by sub-category (Top 5)
- **Slicer**: Category filter for interactive analysis etc.

##  Key Insights
1. West region led in total sales.
2. Technology was the highest-selling category (~36.5%).
3. Top sub-categories include Phones and Chairs.
4. California had the highest state-level sales.
